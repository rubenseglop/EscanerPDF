# Escáner PDF

Aplicación Android para escanear documentos y guardarlos como PDF.

## Características previstas

- Escaneo multipágina con detección automática de bordes.
- Recorte, corrección de perspectiva y rotación.
- Filtros de color, escala de grises y blanco y negro.
- Reordenación y eliminación de páginas.
- Guardar, renombrar, compartir e imprimir documentos.
- Historial local de documentos recientes.

## Requisitos

- Android 10 (API 29) o superior.

## Tecnología

- Kotlin
- Jetpack Compose
- Google ML Kit Document Scanner

La interfaz y el procesamiento de escaneo se apoyan en Google Play Services. Algunas funciones pueden requerir descargar componentes la primera vez.
